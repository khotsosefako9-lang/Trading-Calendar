# Trading-Calendar
This is where I’ll be recording all my trades for the next 2 months

**Open the journal:** https://khotsosefako9-lang.github.io/Trading-Calendar/

Log each day's win or loss and amount, any withdrawals, whether you followed your plan, and notes. The balance starts at R250 and updates from every entry.

Entries are saved in the browser you use, so stick to one device and use **Download backup** regularly. **Restore backup** loads a backup file on any device.
